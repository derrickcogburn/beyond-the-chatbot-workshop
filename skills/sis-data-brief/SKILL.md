# SIS data brief

When asked to analyze or summarize a dataset, follow these steps in order.

## 1. Describe the data first

Before any analysis, state:
- the source of the data, and who collected it
- the units (for example, "thousands of telephones")
- the time period and geographic units covered
- any missing years, missing values, or obvious gaps

## 2. Show your work

- Show every calculation, or the code used to produce it.
- Round sensibly and say how you rounded.

## 3. Cite every source

- Give a link or full reference for every figure that did not come from the uploaded file.
- Note the year each figure refers to.

## 4. Visualize carefully

- Label axes with units.
- Use a log scale when values differ by orders of magnitude, and say so.

## 5. Name the limitations

End with **three limitations** of the data or analysis, written for a graduate-level audience.

## Rules

- Never infer causation from descriptive trends.
- When comparing different units (regions vs. countries, landlines vs. internet access), say so explicitly.
- If a figure cannot be verified, say so rather than estimating.
